## 1. 概述

### 1.1 背景
构建智能报告生成系统，核心能力是基于 AI 驱动报告自动生成，并结合知识库（规则库、财报库、法规库等）实现内容溯源。

### 1.2 范围
本次设计聚焦**报告生成流程**模块，覆盖从用户输入到报告产出、溯源、导出的完整链路。

### 1.3 用户角色
- 业务分析师：日常使用，偏好灵活输入
- 管理人员：快速生成周期性报告，偏好模板填报

---

## 2. 整体布局设计

采用 **混合式智能工作台**，三栏布局：

```
┌──────────────────────────────────────────────────────────┐
│  [智能生成] [模板填报]                        [历史记录] [我的报告] │
├─────────────┬────────────────────────┬────────────────────┤
│  输入区 30%  │     流式生成区 45%      │    操作面板 25%     │
│             │                        │                    │
│ · 对话消息   │  · 流式实时渲染          │ · 溯源引用列表       │
│ · 提示词输入  │  · Markdown/图表/表格    │ · 来源类型标签       │
│ · 历史对话   │  · 引用锚定              │ · 导出格式选择       │
│             │                        │ · 版本历史          │
└─────────────┴────────────────────────┴────────────────────┘
```

**双入口模式**（顶部 Tab 切换）：
- **智能生成**：左侧对话式 AI 输入，用户自然语言描述需求
- **模板填报**：左侧表单，选择模板 + 填写参数后一键生成

## 3. 核心交互流程

### 3.1 完整用户流程

```
用户输入需求
    │
    ▼
┌──────────────┐
│  大纲确认环节  │  ← AI 根据需求生成 5 章大纲，用户确认或修改
└──────┬───────┘
       │ 确认
       ▼
┌──────────────────────────────────────┐
│          三阶段流式生成                │
│  🔍 检索知识库 → 📊 分析数据 → ✍️ 生成报告  │
└──────────────────────────────────────┘
       │
       ▼
┌──────────────┐
│  在线查看 +    │  ← 溯源联动、导出、版本管理
│  多格式导出    │
└──────────────┘
```

### 3.2 大纲确认环节
- 发送需求后，**先生成大纲**，暂不展开正文
- 大纲展示 5 个章节标题和简要描述
- 用户点击「确认」 → 进入流式生成
- 用户点击「修改」 → 返回输入状态，调整需求描述

### 3.3 流式输出
- 采用**逐段流式**输出，不是一次性返回
- 每段（标题/段落）依次渲染，带打字光标动画
- 输出过程中用户可实时阅读，无需等待完整生成

### 3.4 生成进度步骤
在流式生成时，顶部显示三阶段进度条：
- 🔍 检索知识库 — 从规则库/财报库/法规库检索相关数据
- 📊 分析数据 — 对检索结果进行加工、对比、分析
- ✍️ 生成报告 — 逐段流式输出报告正文

三个阶段按序高亮（当前阶段蓝色呼吸灯，已完成阶段绿色）。

## 4. 溯源系统设计

### 4.1 双向联动

| 方向 | 触发方式 | 效果 |
|------|---------|------|
| 右侧→中间 | 点击引用条目 | 中间报告对应段落滚动到视口 + 黄色高亮闪烁 |
| 中间→右侧 | 点击文中 `[N]` 引用标记 | 右侧列表对应条目高亮 |

### 4.2 来源类型标签

每条引用标注来源类型，用不同颜色区分：

| 来源 | 颜色 | 标识 |
|------|------|------|
| 规则库 | 橙色 | 📊 |
| 财报库 | 蓝色 | 📈 |
| 法规库 | 绿色 | 📋 |
| 调研库 | 紫色 | 📝 |

## 5. 导出功能

支持四种导出格式：
- **PDF 文档** — 适用于正式分发、打印
- **Word 文档** — 适用于二次编辑
- **PPT 演示** — 适用于汇报场景

- 每次生成后自动保存版本
- 支持查看历史版本列表
- 支持回滚到任意历史版本

## 7. 技术要点（原型阶段）

- **布局**：CSS Flexbox 三栏自适应，左右固定比例，中间弹性
- **流式渲染**：JavaScript 逐段插入 DOM + 滚动跟随
- **大纲确认**：异步 UI 状态切换，中间区域从大纲卡片切换到报告正文
- **进度条**：CSS class 驱动阶段状态变化
- **溯源联动**：事件委托 + `scrollIntoView` + CSS 动画高亮
- **无依赖**：纯 HTML/CSS/JS，无框架引入

## 8. 设计决策记录

| 决策点 | 选项 | 选择 | 理由 |
|--------|------|------|------|
| 输入方式 | 单一入口 vs 双入口 | 双入口 | 覆盖两类用户习惯 |
| 输出方式 | 一次性 vs 分批 vs 流式 | 流式 | 用户体验最流畅 |
| 大纲确认 | 无 vs 有 | 有 | 避免方向错误浪费算力 |
| 溯源交互 | 静态列表 vs 双向联动 | 双向联动 | 差异化核心卖点 |
| 进度展示 | 简单状态 vs 三阶段 | 三阶段 | 对齐架构图层级，增加透明感 |

└───────────┴──────────────────────────────────────────────┘

### 9.2 核心功能

#### 知识库导航
- 预设 4 个知识库：规则库、财报库、法规库、调研库
- 展示每个库的条目数量
- 支持管理员新建自定义知识库（业务人员视角隐藏入口）
- 点击切换知识库，右侧内容联动刷新

#### 概览统计卡片
- 知识条目总数（含本月新增比例）
- 索引状态（百分比）
- 数据源同步状态（最近同步时间）
- 引用命中率（近30天）

#### 三种入库方式
| 方式 | 说明 | 交互形式 |
|------|------|---------|
| 手动录入 | 填写标题、内容（支持Markdown）、选择知识库和类型 | 右侧抽屉面板 |
| 文件上传 | 上传 PDF/Excel/Word/CSV/TXT，自动解析入库 | 拖拽上传 + 进度条 |
| 数据源对接 | 对接数据库/API/定时拉取，配置连接参数 | 表单配置 + 测试连接 |

#### 知识条目管理
- **表格展示**：知识条目、类型标签、所属库、更新时间、状态、操作
- **分页功能**：首页/上一页/页码/下一页/末页，支持每页 5/10/20/50 条切换
- **搜索筛选**：关键词搜索 + 按类型（文档/规则/数据）筛选，筛选结果自动分页
- **批量操作**：表头复选框支持全选
- **行操作**：查看详情、删除条目

#### 角色权限
- **管理员**：全部管理权限，可新建知识库、管理所有条目
- **业务人员**：查看权限，不显示新建知识库入口

### 9.3 交互设计

- **抽屉面板**：录入/上传/数据源对接均使用右侧滑出抽屉，操作完成自动关闭
- **上传进度**：模拟进度条动画，解析完成后按钮激活
- **分页联动**：搜索/筛选/切换知识库后自动重置为第 1 页
- **状态标签**：正常（绿色 ✓）、待审核（黄色 ⚠）、异常（红色 ✕）

### 9.4 技术要点（原型阶段）

- **布局**：CSS Flexbox 双栏，左侧固定 220px，右侧自适应
- **分页**：前端纯 JS 切片渲染，翻页按钮事件委托
- **抽屉/弹窗**：CSS `transform` 动画 + 遮罩层控制
- **数据**：纯前端 mock 数据，`kbData` 对象管理各库条目
- **无依赖**：纯 HTML/CSS/JS，无框架引入

- 画布：SVG 或 Canvas 实现节点 + 连线渲染
- 拖拽：HTML5 Drag & Drop API
- 连线：SVG path 贝塞尔曲线自动连接节点端口
- 节点库：JSON Schema 定义各节点类型的输入输出规范
- 调试：模拟规则执行，mock 各节点的处理逻辑

- 角色数据：JSON 模拟用户数据库，`currentRole` 全局状态控制 UI 显隐

- 分享链接：前端模拟带 token 的 URL，进入时校验 token 有效性

### 11.3 跨页面全局功能

#### 角色管理（7个页面均已实现）
- **存储**：`localStorage.getItem/setItem('currentRole')` 持久化
- **UI**：侧边栏底部角色下拉组件，4种角色切换（管理员/高级分析师/分析师/查看者）
- **同步**：切换角色后自动更新头像、名称，高亮当前选项
- **配置**：`roleConfig` 对象统一管理角色名称、头像字符、主题色

#### 导航高亮
- 基于 `location.pathname` 自动匹配当前页面，对应的 `.nav-item` 添加 `.active` 高亮

### 11.4 规则引擎 (rule-engine.html) 实现详情

#### 画布交互系统
- **缩放**：鼠标滚轮以指针位置为中心，范围 0.3x ~ 2.0x，右下角显示缩放百分比
- **平移**：中键拖拽或 Ctrl+左键拖拽空白区域
- **状态指示**：`.panning`(grabbing 光标) / `.connecting`(crosshair 光标)

#### 连线系统
- **SVG 贝塞尔曲线**：`M... C...` 路径 + `<marker>` 箭头标记
- **创建**：点击输出端口 `startConnection()` → 鼠标跟随虚线 → 点击输入端口 `endConnection()`
- **删除**：点击连线选中(变红) → 再次点击确认删除
- **防重复**：`connections.some()` 检查已存在连线
- **ESC 取消**：`keydown` 监听 Escape 键

#### 节点系统
- **拖入职建**：HTML5 Drag & Drop API，`data-ntype/nicon/ntitle/ndesc` 属性传递
- **画布内拖拽**：`mousedown/mousemove/mouseup` 事件链，拖动时连线实时跟随
- **类型映射**：`typeClassMap` 将 ntype → CSS 类 (node-input/parse/classify/link/output)
- **端口**：输入节点只含 out 端口，输出节点只含 in 端口，中间节点两者都有

#### 调试系统
- **全程执行**：`setTimeout` 链式调用，每步 500ms，逐步高亮画布节点
- **高亮动画**：`debug-active`(黄色边框+脉冲 @keyframes debugPulse) → `debug-done`(绿色边框)
- **单步执行**：仅高亮第一步，日志追加

### 11.5 用户权限 (user-permission.html) 实现详情

#### 批注系统
- **选中文本**：`.highlight` 元素带 tooltip，点击 `addAnnotation()` 打开输入弹窗
- **弹窗**：包含选中文本预览、批注内容 textarea、指派对象下拉
- **提交**：更新高亮文本样式(黄色背景)、tooltip 文字、在批注列表面板插入新条目、更新标签计数

#### 分页系统
- **用户管理**：5条/页，页码智能截断(最多显示5个)，renderUserTable + renderUserPagination
- **操作日志**：5条/页，renderLogList + renderLogPagination
- **权限矩阵**：11项权限 × 4种角色，renderPermMatrix 动态渲染

#### 协作面板
- **4个Tab**：分享(链接+用户)、批注(含已解决/待处理状态)、版本(V1~V3可回滚)、任务(指派+截止日期)

### 11.6 知识库管理 (knowledge-base.html) 实现详情

#### 三种入库方式
- **手动录入**：右侧抽屉面板，填写标题/内容/类型/标签，保存后实时更新表格和统计
- **文件上传**：拖拽区域 + 模拟进度条动画
- **数据源对接**：支持数据库/API/定时拉取三种类型，动态切换配置表单，含测试连接按钮

#### 角色差异
- 顶部角色徽章切换管理员/业务人员，业务人员视角隐藏"新建知识库"入口

### 11.7 技术栈（全部页面统一）

| 层面 | 选型 |
|------|------|
| 语言 | 纯 HTML/CSS/JS，无框架依赖 |
| 布局 | CSS Flexbox 多栏布局 |
| 状态 | 前端 mock 数据 + localStorage 持久化 |
| 动画 | CSS transition/animation + setTimeout 链式 |
| 图表 | 内联 SVG（折线图、柱状图、贝塞尔连线） |
| 弹窗 | CSS overlay + modal 层叠 |
| 拖拽 | HTML5 Drag & Drop API + 原生 mousedown 事件 |
| 兼容 | 仅需现代浏览器（Chrome/Edge/Firefox） |

### 11.8 设计决策回顾

| 决策点 | 选项 | 选择 | 理由 |
|--------|------|------|------|
| 全局导航 | 每个页面独立 vs 统一侧边栏 | 统一侧边栏 | 一致性体验，减少用户认知负担 |
| 角色切换 | 各页面独立 vs 全局持久化 | 全局 localStorage | 跨页面状态统一，无需重复设置 |
| 规则画布 | 静态展示 vs 全交互 | 全交互 | 原型阶段验证完整用户流程 |
| 连线渲染 | DOM 元素 vs SVG | SVG 贝塞尔曲线 | 平滑美观，支持箭头和动画 |
| 批注输入 | 内联 vs 弹窗 | 独立弹窗 | 信息更完整，支持指派等扩展字段 |
| 分页策略 | 后端分页 vs 前端切片 | 前端切片 | 原型阶段数据量小，快速验证交互 |
