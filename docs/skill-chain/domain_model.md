# 智能报告生成系统领域模型

> Skill：S3 domain_modeling  
> 输入：`requirements.md`、`user_journey.md`  
> 输出：DDD 领域模型与 OpenSpec capability 映射。

## 1. 建模原则

| 原则 | 说明 |
| --- | --- |
| 需求可追溯 | 所有领域对象必须能追溯到 Requirement ID 和 UC |
| DDD 优先 | 使用限界上下文、聚合根、实体、值对象和领域事件表达业务边界 |
| AI 业务一体化 | RAG、引用评分、模型调用审计是业务闭环的一部分 |
| 范围克制 | 当前不建模多租户、私有化、高可用、灾备和人工审核发布 |
| 可交付导向 | 模型服务于真实闭环，不服务于纯页面或接口骨架 |

## 2. 限界上下文

| 限界上下文 | 类型 | 核心职责 | 追溯 |
| --- | --- | --- | --- |
| 报告生成上下文 | 核心 | 自然语言/模板生成、任务状态机、大纲确认、三阶段流式生成 | REQ-REPORT-001/002, REQ-AI-001, UC-01/02 |
| 溯源导出版本上下文 | 核心 | 引用锚点、来源快照、证据评分、导出、版本回滚 | REQ-REPORT-003/004/005, UC-03/04/14 |
| 知识库上下文 | 核心 | 知识库、知识条目、文件上传、数据源同步、索引状态 | REQ-KB-001/002/003, UC-05/06/07 |
| AI 检索生成上下文 | 支撑 | RAG、Embedding、Prompt、线上 GPT、多模型路由预留 | REQ-AI-001, UC-01/03 |
| 规则引擎上下文 | 支撑 | 规则节点、画布连线、参数配置、调试执行 | REQ-RULE-001, UC-08 |
| 权限协作上下文 | 通用 | RBAC、分享链接、批注、评论、任务、通知 | REQ-AUTH-001, REQ-COLLAB-001/002, UC-09/10/11 |
| 审计历史工作台上下文 | 通用 | 操作日志、个人历史、管理员审计、模型调用审计、工作台聚合 | REQ-AUDIT-001, REQ-DASH-001, UC-12/13 |
| 范围护栏上下文 | 约束 | 排除多租户、私有化、HA/DR、人工审核发布 | REQ-SCOPE-001 |

## 3. 聚合根

| 聚合根 | 所属上下文 | 核心职责 | 包含实体 |
| --- | --- | --- | --- |
| 报告 | 报告生成 | 管理正文、状态、引用、版本、导出和授权边界 | 报告段落、报告版本、导出文件 |
| 报告生成任务 | 报告生成 | 跟踪输入、大纲、阶段进度、失败原因和结果 | 生成阶段、生成片段 |
| 报告模板 | 报告生成 | 定义模板字段、校验规则和模板版本 | 模板字段、模板参数 |
| 知识库 | 知识库 | 管理知识分类、条目、访问范围和索引状态 | 知识条目、知识标签 |
| 知识文档 | 知识库 | 承载上传文件、解析结果、片段和索引状态 | 文档片段、解析结果、Embedding |
| 数据源连接 | 知识库 | 管理企业数据源连接、测试结果和同步策略 | 同步任务、同步日志 |
| 检索会话 | AI 检索生成 | 记录召回、重排、上下文压缩和引用候选 | 检索结果、上下文片段 |
| 模型调用记录 | AI 检索生成 | 审计 Prompt、上下文、参数、响应、耗时和结果 | Prompt 快照、模型响应 |
| 引用来源 | 溯源导出版本 | 维护来源快照、评分和正文锚点 | 引用锚点、来源快照 |
| 规则 | 规则引擎 | 管理节点、连线、版本和可运行状态 | 规则节点、规则连线、规则版本 |
| 规则执行记录 | 规则引擎 | 记录调试与运行过程 | 节点执行日志 |
| 用户 | 权限协作 | 管理账号、部门、状态和角色关系 | 用户角色关系 |
| 角色 | 权限协作 | 管理权限项集合 | 权限项 |
| 分享链接 | 权限协作 | 控制外部访问范围、密码、有效期和撤销状态 | 访问记录 |
| 批注 | 权限协作 | 管理报告文本位置、评论、任务和状态 | 评论、任务 |
| 操作日志 | 审计历史工作台 | 记录关键操作和上下文 | 日志详情 |
| 工作台指标 | 审计历史工作台 | 聚合趋势、排行和最近活动 | 趋势点、排行项、活动记录 |

## 4. 关键值对象

| 值对象 | 描述 | 不变量 |
| --- | --- | --- |
| 报告主题 | 用户生成意图、时间范围、分析维度和关注重点 | 创建后作为输入快照不可原地修改 |
| 报告风格 | 标准专业、高管摘要、详细分析等输出风格 | 作为生成参数快照保存 |
| 导出版式 | 格式、目录、页眉页脚、Logo、字体、颜色 | 导出请求内不可变 |
| 引用编号 | 正文引用显示文本和段落位置 | 生成后不可变 |
| 证据评分 | 相关性、时效性、权威性、覆盖度和总分 | 单次评估结果不可变 |
| Prompt 快照 | 系统提示、用户输入、检索上下文和模板变量 | 审计快照不可变 |
| 模型参数 | 模型名、温度、最大长度、流式标记 | 单次调用不可变 |
| Embedding | 向量、模型、维度、生成时间 | 生成后不可变 |
| 连接配置摘要 | 数据源类型、地址摘要、同步策略 | 不保存明文凭据 |
| 有效期 | 分享链接时间边界 | 过期后不得放行 |
| 访问密码策略 | 分享访问保护策略 | 密码只存哈希 |
| 分页条件 | 页码、每页数量、排序字段 | 请求内不可变 |

## 5. 核心领域事件

| 领域事件 | 触发条件 | 后续影响 | 追溯 |
| --- | --- | --- | --- |
| 报告需求已提交 | 用户提交自然语言或模板参数 | 创建报告生成任务 | REQ-REPORT-001 |
| 报告大纲已确认 | 用户确认或修改大纲 | 启动 RAG 和正文生成 | REQ-REPORT-002 |
| 知识检索已完成 | RAG 召回和重排完成 | 形成模型上下文和引用候选 | REQ-REPORT-003 |
| 模型调用已完成 | GPT 返回响应 | 更新报告内容并记录审计 | REQ-AI-001 |
| 引用已锚定 | 段落关联来源 | 支持双向定位和评分展示 | REQ-REPORT-003 |
| 报告已导出 | 导出文件生成 | 记录下载地址和导出审计 | REQ-REPORT-004 |
| 报告版本已回滚 | 用户选择历史版本 | 创建新的当前版本 | REQ-REPORT-005 |
| 知识文档已上传 | Java 完成文件存储和元数据登记 | 发布解析事件 | REQ-KB-002 |
| 知识文档已解析 | Python 完成解析、分块和索引 | 知识条目进入可检索状态 | REQ-KB-002 |
| 数据源同步异常 | 连接或同步失败 | 记录异常和审计 | REQ-KB-003 |
| 规则执行已失败 | 参数缺失、连线非法或运行失败 | 写入调试日志 | REQ-RULE-001 |
| 分享链接已生成 | 用户配置分享策略 | 外部用户可受控访问 | REQ-COLLAB-001 |
| 批注任务已指派 | 用户提交批注并选择处理人 | 生成任务和通知 | REQ-COLLAB-002 |
| 权限校验已拒绝 | 用户访问未授权资源 | 拒绝访问并写审计 | REQ-AUTH-001 |
| 审计记录已生成 | 关键操作或模型调用完成 | 支持历史和审计查询 | REQ-AUDIT-001 |

## 6. 聚合不变量

| 聚合 | 不变量 |
| --- | --- |
| 报告 | 未确认大纲不得进入正文生成；导出必须关联报告版本；回滚只能创建新版本 |
| 报告生成任务 | 阶段顺序必须可追踪；失败必须保留可见原因；模型调用必须关联审计 |
| 知识库 | 删除被引用条目前必须提示影响；可检索前必须有索引状态 |
| 知识文档 | OCR、表格识别或扫描件解析失败必须记录原因 |
| 数据源连接 | 测试连接失败不得保存为可同步状态 |
| 检索会话 | 检索结果必须可回溯到知识条目或文档片段 |
| 模型调用记录 | Prompt、上下文、参数、响应和结果必须留痕 |
| 分享链接 | 过期、撤销或密码错误必须拒绝访问 |
| 批注 | 必须关联报告位置或报告对象；任务必须有处理人和状态 |
| 操作日志 | 普通用户不得查看全局审计 |
